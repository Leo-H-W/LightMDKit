> 本文档是项目知识库的索引和导航，用于快速了解项目结构和查找详细文档。

## 基本信息

| 项目名称 | md-view |
|---------|--------|
| 项目简介 | 本地 Markdown 查看器，支持 GitHub 风格渲染、左侧目录导航、文件刷新和在线编辑 |
| 主要语言 | JavaScript |
| 核心框架 | Express, marked |
| 分析版本 | 非 Git 仓库（SVN 管理） |
| 生成时间 | 2026-04-30 |

## 模块功能介绍

### 核心模块

| 模块名称 | 功能描述 | 目录路径 | 相关技术 |
|---------|---------|---------|---------|
| 后端服务 | HTTP 服务器（端口 3456），提供文件夹选择、文件加载、文件读取、文件刷新等 API，支持守护进程模式运行 | `md-view/server.js` | Express, Node.js |

|---------|---------|---------|

## API 接口概览

| 接口 | 方法 | 功能描述 |
|------|------|---------|
| `/api/select-folder` | POST | 打开 Windows 系统文件夹选择对话框（通过 PowerShell） |
| `/api/load` | POST | 加载指定文件夹，扫描 Markdown 文件列表并可选加载首个文件 |
| `/api/file` | GET | 读取指定路径的文件内容并返回 Markdown 和 HTML |
| `/api/refresh` | POST | 刷新指定文件内容 |
