## 文档加载流程

### 1. 文件夹加载流程

**入口**: 前端 UI 交互 (`md-view/public/app.js:208`) - `selectFolder()`

**核心步骤**:
1. 调用 `window.showDirectoryPicker` 弹出系统文件夹选择对话框
2. 遍历目录 entries，筛选 `.md` / `.markdown` 文件
3. 文件列表按名称排序后存入 `currentFiles` 状态
4. 自动选中并加载第一个文件

**主要异常分支**:
- 浏览器不支持 `showDirectoryPicker` API → 提示使用 Chrome 或 Edge
- 用户取消选择 → 捕获 `AbortError`，显示已取消提示
- 目录下无 Markdown 文件 → 显示空状态提示

**涉及代码**:
- 前端交互: `md-view/public/app.js:208-256`

### 2. 文件渲染流程

**入口**: `loadFile(name)` / `renderFile(fileEntry)` (`md-view/public/app.js:198`)

**核心步骤**:
1. 通过 `FileSystemFileHandle.getFile()` 获取文件对象
2. 读取文件文本内容
3. 调用 `marked.parse()` 将 Markdown 渲染为 HTML
4. 解析标题偏移量，生成目录 (TOC) 并设置 IntersectionObserver

**主要异常分支**:
- 文件不存在于 currentFiles 列表中 → 静默返回
- 文件读取失败 → 显示错误提示

**涉及代码**:
- 渲染逻辑: `md-view/public/app.js:198-206`
- 文件加载: `md-view/public/app.js:258-279`

## 文档编辑流程

### 3. 编辑模式切换与保存流程

**入口**: `toggleEditMode()` (`md-view/public/app.js:388`)

**核心步骤**:
1. 切换编辑/浏览模式：记录当前视口顶部 heading id
2. 编辑模式：显示 textarea，填充 Markdown 原文，定位光标到可见区域
3. 保存时：通过 `createWritable()` 写入文件
4. 切回浏览模式：重新渲染 HTML，恢复滚动位置

**主要异常分支**:
- 未加载文件 → 提示先加载文件
- 文件写入失败 → 显示保存失败错误

**涉及代码**:
- 模式切换: `md-view/public/app.js:388-433`
- 文件保存: `md-view/public/app.js:371-386`

### 4. 文件刷新流程

**入口**: `refreshCurrentFile()` (`md-view/public/app.js:281`)

**核心步骤**:
1. 重新扫描当前文件夹，发现新增/删除的文件
2. 更新 `currentFiles` 列表并刷新下拉选择框
3. 若当前文件被移除则显示空状态
4. 否则重新读取并渲染当前文件

**主要异常分支**:
- 未加载文件或未加载文件夹 → 提示相应操作
- 当前文件已被移除 → 显示已移除错误

**涉及代码**:
- 刷新逻辑: `md-view/public/app.js:281-335`

## 文档导航流程

### 5. 文档内链接跳转流程

**入口**: `contentEl` 的 `click` 事件监听器 (`md-view/public/app.js:340`)

**核心步骤**:
1. 拦截文档内链接点击事件，过滤外部链接和锚点
2. 解码 URL，提取目标文件名
3. 在 `currentFiles` 中查找匹配项，将当前文件推入历史栈
4. 调用 `loadFile()` 加载目标文件

**主要异常分支**:
- 目标文件不在已加载列表中 → 不拦截，走默认链接行为
- 外部链接或锚点 → 不拦截

**涉及代码**:
- 链接拦截: `md-view/public/app.js:340-358`

### 6. 返回上一文档流程

**入口**: `btnBack` 的 `click` 事件监听器 (`md-view/public/app.js:364`)

**核心步骤**:
1. 从 `fileHistory` 栈弹出上一个文件名
2. 调用 `loadFile()` 加载历史文件
3. 更新返回按钮的可用状态

**主要异常分支**:
- 历史栈为空 → 按钮禁用，无操作

**涉及代码**:
- 返回逻辑: `md-view/public/app.js:360-369`

### 7. 目录交互与高亮流程

**入口**: `renderToc()` (`md-view/public/app.js:111`) / `setupTocObserver()` (`md-view/public/app.js:493`)

**核心步骤**:
1. 从已渲染 HTML 中提取所有 heading 元素
2. 为每个 heading 生成唯一 id，创建目录项
3. 设置 IntersectionObserver 监听 heading 可见性
4. 滚动时自动高亮当前最上方可见 heading 对应的目录项

**主要异常分支**:
- 文档无标题 → 显示"当前文件没有标题目录"
- 标题 id 重复 → 自动追加序号去重

**涉及代码**:
- TOC 渲染: `md-view/public/app.js:111-151`
- 滚动监听: `md-view/public/app.js:493-512`

## 后台服务流程

### 8. 后端服务启动与管理流程

**入口**: `main()` 函数 (`md-view/server.js:308`)

**核心步骤**:
1. 检查端口 3456 是否被占用
2. 端口空闲：spawn 守护进程，父进程退出
3. 端口占用：查找占用进程 PID，提供重启或显示 URL 选项
4. 守护进程启动 Express 服务，监听端口并响应请求

**主要异常分支**:
- 端口占用且重启失败 → 显示访问 URL
- 守护进程启动时端口冲突 → 输出错误并退出

**涉及代码**:
- 服务入口: `md-view/server.js:308-349`
- 守护进程: `md-view/server.js:282-306`
- 端口检测: `md-view/server.js:268-280`
